🐝 智蜂专家 · RAG 蜜源信息推荐系统
基于 MySQL + Chroma 向量库 + 大模型的蜜源智能问答与推荐

这是什么

一个面向蜂农与养蜂技术人员的 RAG（检索增强生成） 应用：把蜜源植物资料（分布、花期、产蜜量、气候） 与养蜂知识组织成可检索知识库，通过 SQL 结构化筛选 + 向量语义排序 召回相关内容， 再由大模型生成准确、可追溯的回答，并标注信息来源。

智能问答蜜源推荐地图分布 多轮对话Token 用量统计

核心能力

混合检索
结构化硬条件 + 语义向量精排，召回更准。
多轮指代消解
「那里产蜜量高吗？」自动补全为可检索查询。
离线向量模型
本地 bge-small-zh，无需任何 Embedding 密钥。
LLM 评测
LangSmith + LLM-as-Judge 量化回答正确率。

本地快速开始

# 安装依赖
pip install -r requirements.txt

# 准备配置（复制样例，填入你自己的 LLM_API_KEY）
cp .env.example .env

# 准备 MySQL 数据库（建表）
python init_db.py

# 启动（首次自动下载向量模型并构建向量库）
python app.py
# 浏览器打开 http://127.0.0.1:5000
⚠️ 本页面是 GitHub Pages 托管的项目主页 / 文档。 Pages 只能托管静态网页，无法运行 Flask 后端。要让他人在线使用， 需把后端部署到云服务器 / 容器平台，再绑定域名。

评测结果（示例）

使用 LangSmith + LLM-as-Judge 评测单轮问答：correctness 0.87~0.94， has_sources 1.00（回答均带可追溯来源）。多轮脚本额外验证查询重写的指代消解是否正确。

安全说明

  • 所有密钥（DeepSeek / LangSmith）放在 .env 中，已被 .gitignore 忽略，绝不进仓库。
  • 评测脚本不内置任何明文密钥，全部从环境变量或 .env 读取。
  • 若密钥曾泄露，请立即在对应平台吊销重置。
